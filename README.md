# 🚀 Frontend Dasturlash: To'liq Nazariya va Amaliyot Jurnali

Ushbu repozitoriy Frontend dasturlash bo'yicha kundalik o'rganilgan va amaliyotda qo'llanilgan barcha mavzularni o'z ichiga oladi.

> **Qoida**: Bir kun chuqur **Nazariy Konspekt** (`konspektlar/`), bir kun mustaqil **Amaliy Kod** (`amaliyot/`).

---

## 📚 O'quv Rejasi (Roadmap):
1. **1-bosqich**: HTML5 Semantikasi, Modern CSS, Flexbox, Grid, Responsive Design va Web Vitals
2. **2-bosqich**: JavaScript Core (V8, Event Loop, Closures, Prototypes, Asinxron dasturlash)
3. **3-bosqich**: TypeScript Advanced (Generics, Conditional Types, Type Narrowing, SOLID)
4. **4-bosqich**: React 19, Custom Hooks, Context, Virtual DOM va Zustand State Management
5. **5-bosqich**: Next.js App Router, Server Actions, Caching, Middleware va Optimizatsiya
