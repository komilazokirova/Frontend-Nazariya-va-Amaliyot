# 🛠️ TypeScript Utility Types

TypeScript taqdim etadigan eng muhim transformatsiya turlari:

* `Partial<T>`: Barcha xususiyatlarni ixtiyoriy (`?`) qiladi.
* `Required<T>`: Barcha xususiyatlarni majburiy qiladi.
* `Readonly<T>`: Xususiyatlarni faqat o'qish uchun qiladi.
* `Pick<T, K>`: Belgilangan kalitlarni ajratib oladi.
