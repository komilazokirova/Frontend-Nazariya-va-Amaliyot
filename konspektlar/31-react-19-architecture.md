# ⚛️ React 19 Arxitekturasi va Yangi Xususiyatlari

React 19 da manual memoizatsiya (`useMemo`, `useCallback`) React Compiler tomonidan avtomatlashtiriladi.

## Yangi hooklar:
* `useActionState`: Server yoki Client asinxron form amallarining holatini (state, pending, error) boshqarish.
* `useFormStatus`: Form ichidagi submit tugmasi uchun yuklanish holatini avtomatik aniqlash.
* `useOptimistic`: Server javobini kutmasdan UI ni darhol yangilash.
