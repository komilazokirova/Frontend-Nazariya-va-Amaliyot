# ⏳ React Suspense va Concurrent Rendering

Concurrent React bir vaqtning o'zida bir nechta render ustida ishlash va ularni prioritet bo'yicha boshqarish imkonini beradi.

* **`Suspense`**: Ma'lumot yuklanayotganda yuklanish indikatorini (Skeleton/Spinner) deklarativ ko'rsatish.
* **`useTransition`**: Og'ir UI yangilanishlarini past prioritetli (non-blocking) qilib belgilash, natijada kiritish maydoni (input) qotib qolmaydi.
